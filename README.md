# Etch-a-Sketch

A browser-based sketchpad inspired by the classic Etch A Sketch toy, built as part of [The Odin Project](https://www.theodinproject.com/) Foundations curriculum.

## Features

- **Dynamic Grid Generation:** Configurable grid dimensions (up to 100x100 squares) contained within a fixed 960px canvas.
- **Random RGB Colors:** Each square acquires a randomized color on the first mouse hover.
- **Progressive Darkening:** Each subsequent hover darkens the square by 10%, reaching completely black after 10 passes.
- **Grid Controls:**
  - **Change size:** Prompts for a new resolution and redraws the canvas.
  - **Clear:** Resets the current grid without asking for the size again.

## Tech Stack

- **HTML5:** Semantic structure.
- **CSS3:** Flexbox layout and responsive constraints.
- **JavaScript (Vanilla):** DOM manipulation, event listeners, and dataset state tracking.
